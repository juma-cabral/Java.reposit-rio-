# ☕ Maratona Java - DevDojo

Repositório de Estudos | Desenvolvimento Back-End com Java

Este repositório foi criado para organizar todos os códigos, anotações, exercícios e desafios práticos desenvolvidos por mim durante a **Maratona Java**, ministrada pelo William Suane no **DevDojo**. O objetivo é consolidar a minha base em lógica de programação, orientação a objetos e recursos avançados da linguagem Java.

---

##  Tecnologias Utilizadas

- **Java**
- **IntelliJ IDEA** (IDE utilizada para o desenvolvimento)
- **Git & GitHub** (Controle de versão)

---

##  Evolução e Conteúdos Aprendidos

Abaixo está a divisão dos módulos e tópicos que já estudei e implementei até o momento:

### 🟩 Módulo 1: Fundamentos da Linguagem
- [x] Configuração do ambiente de desenvolvimento (JDK e IDE).
- [x] Variáveis, tipos primitivos (int, double, float, char, boolean) e convenções de nomenclatura.
- [x] Operadores aritméticos, relacionais, lógicos e de atribuição.
- [x] Estruturas condicionais (`if`, `else if`, `else`, `switch`).
- [x] Estruturas de repetição (`while`, `do-while`, `for`).
- [x] Arrays unidimensionais e multidimensionais (Matrizes).

### 🟦 Módulo 2: Orientação a Objetos (Introdução ao Avançado)
- [x] Criação de Classes, Atributos e Métodos.
- [x] Passagem de parâmetros e sobrecarga de métodos.
- [x] Construtores e blocos de inicialização.
- [x] Modificadores de acesso (`private`, `public`, `protected`) e Encapsulamento (Getters e Setters).
- [x] Associação entre classes (Agregação e Composição).
- [x] Herança e Sobrescrita de métodos (`@Override`).
- [x] Modificador `final` (Classes, Métodos e Variáveis).
- [ ] Polimorfismo e Classes Abstratas.
- [ ] Interfaces.
